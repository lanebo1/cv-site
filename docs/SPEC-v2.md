# ТЗ v2 — РЕДИЗАЙН: бело-оранжевый, светлое пламя, цветасто

Полный редизайн существующего сайта (код в /opt/data/cv-v2, структура/контент сохранить —
меняется ТОЛЬКО дизайн-слой: цвета, фон, анимации, шрифты, детали компонентов).

## Дизайн-система: WHITE + FLAME

- Фон: тёплый белый #fffdf9 → секции чуть варьировать (#fff8f0).
- Текст: почти-чёрный тёплый #1c1917, вторичный #78716c.
- Акцент: живой оранжевый #f97316 → градиент оранжевый-янтарь (#f97316 → #fbbf24 → #fb923c).
- Цветные чипы навыков: каждая группа своего цвета (teal, violet, rose, sky, amber, lime — пастельные фоны + насыщенный текст).
- Тёмной темы БОЛЬШЕ НЕТ — удалить переключатель и весь dark-код (упрощение).

## «Пламя» и графика

1. **Hero-фон: живой flame-градиент** — анимированные размытые плазменные пятна
   (оранж/янтарь/розовый, blur 100-140px, медленно дрейфуют по синусоиде, opacity 0.5-0.7)
   поверх белого. Реализовать CSS-анимацией (keyframes translate/scale, GPU transform) —
   div-«пятна» за контентом. Плавно, легко, без canvas.
2. **Заголовок hero**: градиентный текст (bg-clip-text, оранжево-янтарный градиент)
   с лёгким blur-in появлением.
3. **Кнопки**: shimmer-эффект (блик пробегает при hover), оранжевая заливка.
4. **Карточки**: белые с тонкой оранжевой рамкой-градиентом при hover (animated border),
   мягкая тень с оранжевым оттенком.
5. **Таймлайн опыта**: линия-градиент оранж→янтарь, точки с пульсацией (scale+glow loop).
6. **Счётчики достижений**: цветные (каждый свой оттенок), число с count-up анимацией.
7. **Чипы навыков**: цветные по группам, hover — лёгкий lift + цветная тень.
8. **Прогресс-полоса скролла** сверху страницы: оранжево-янтарный градиент.
9. prefers-reduced-motion — уважать (анимации отключать).

## Библиотеки/подход

Framer Motion (стоит) + CSS keyframes. Стиль компонентов — как Magic UI / React Bits
(светлые версии): blur-in текст, aurora-фон, shimmer, magnetic hover на CTA.
Сторонние пакеты НЕ добавлять (кроме уже стоящих) — компоненты написать руками.
